# Tablet prototype design reference

The HTML file in this directory is the original prototype supplied for the Natball Insights redesign. Use it to compare screen layout, colors, typography, icons, navigation, overlays, and the coach journey described in [specification #108](https://github.com/mecster09/awesome-shot/issues/108).

The existing app and specification #108 govern match data, validation, persistence, correction, export, and lifecycle rules. The prototype contains sample values, placeholder controls, and browser CDN dependencies. It is reference material and is not part of the production app or offline bundle.
